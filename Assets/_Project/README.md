# Project Assets

This folder contains project-owned Unity assets for PODECK_3D.

- `Scripts`: Runtime gameplay, UI, scene flow, and audio scripts.
- `Scenes`: Playable and loading scenes.
- `Prefabs`: Project prefabs.
- `Materials`: Project materials.
- `UI`: Project UI-only assets.
- `Audio`: Project audio and sound effects.
- `Editor`: Unity editor setup tools used by this project.
- `Settings`, `Resources`, `Models`, `Sprites`, `Animations`, `Characters`, and `Fonts`: Project-supporting assets currently referenced by scenes or prefabs.

Imported external assets live in `Assets/ThirdParty`.
Paid or license-restricted assets live in `Assets/PaidAssets` and are ignored by Git when required.
